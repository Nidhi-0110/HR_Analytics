# HR Analytics Website

This folder contains a React + TypeScript dashboard scaffold for the HR Analytics project.
The website is built with Vite, Tailwind CSS, and reusable chart components for future HR data visualization.

## Features

- React + TypeScript frontend
- Vite development server
- Tailwind CSS styling
- Support for dashboard charts and HR metrics

## Setup

1. Open a terminal in `HR_Analytics_Website`.
2. Install dependencies:

```bash
npm install
```

## Development

Start the local development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal.

## Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Recommended Improvements

- Add API integration to load HR analytics data from the model or backend
- Build chart components for attrition, department breakdown, and salary trends
- Connect the website to a deployed machine learning service
- Add navigation and dashboard cards for HR KPI summaries

## Notes

This folder is currently a frontend scaffold, ready to be extended into a full HR analytics dashboard.
